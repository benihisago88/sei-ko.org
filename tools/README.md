# お問い合わせの控えをスプレッドシートに残す設定

メールが迷惑メールに落ちたり、サーバーの都合で届かなかった場合の保険として、
お問い合わせ内容を Google スプレッドシートにも記録します。

送信するのはブラウザではなく `contact.php`（サーバー）です。
そのため `.htaccess` の CSP（`connect-src 'self'` / `form-action 'self'`）は
一切緩める必要がありません。

## 手順

1. Google ドライブで新しいスプレッドシートを作る（名前は任意）。
2. そのシートで「拡張機能」→「Apps Script」を開く。
3. エディタの中身をすべて消し、[google-sheets-relay.gs](google-sheets-relay.gs) の内容を貼り付けて保存。
4. 右上の「デプロイ」→「新しいデプロイ」を選ぶ。
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 初回は Google の承認画面が出るので許可する
   （「このアプリは確認されていません」→「詳細」→「安全ではないページに移動」で進めます）。
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー。
7. `contact.php` の `SHEET_ENDPOINT` にその URL を貼る。

```php
const SHEET_ENDPOINT = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

これで完了です。シートは初回の書き込み時に「お問い合わせ」という名前で
見出し行付きで自動作成されます。

## 動作確認

サイトのフォームから自分宛にテスト送信し、メールとシートの両方に
届くか確認してください。シートにだけ入らない場合は、サーバーの
エラーログに `contact.php: sheet forward failed` が出ています。

## 注意

- `SECRET` は `contact.php` の `SHEET_SECRET` と同じ値である必要があります。
  変更する場合は必ず両方を書き換えてください。
- **Apps Script のコードを直したら、毎回デプロイし直す必要があります**
  （「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」）。
  保存しただけでは公開中の URL に反映されません。
- この `tools/` ディレクトリは合言葉を含むため、同梱の `.htaccess` で
  Web からのアクセスを禁止しています。削除しないでください。
- `SHEET_ENDPOINT` を空文字にすれば、記録処理は丸ごと止まります。
