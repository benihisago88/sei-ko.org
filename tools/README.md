# お問い合わせの控えをスプレッドシートに残す設定

メールが迷惑メールに分類されたり、サーバーの都合で届かなかった場合の
バックアップとして、お問い合わせ内容を Google スプレッドシートにも記録します。

送信元はブラウザではなく `contact.php`（サーバー）です。
そのため `.htaccess` の CSP（`connect-src 'self'` / `form-action 'self'`）を
緩める必要はありません。

## 手順

1. Google ドライブで新しいスプレッドシートを作成する（名前は任意）。
2. そのシートで「拡張機能」→「Apps Script」を開く。
3. エディタの内容をすべて削除し、[google-sheets-relay.gs](google-sheets-relay.gs) の内容を貼り付けて保存する。
4. 右上の「デプロイ」→「新しいデプロイ」を選択する。
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 初回は Google の承認画面が表示されるので許可する。
   （「このアプリは確認されていません」→「詳細」→「安全ではないページに移動」で進める）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーする。
7. `contact.php` の `SHEET_ENDPOINT` にその URL を設定する。

```php
const SHEET_ENDPOINT = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

シートは初回の書き込み時に「お問い合わせ」という名前で見出し行付きで
自動作成されます。

## 動作確認

サイトのフォームから自分宛にテスト送信し、メールとシートの両方に
記録されるか確認してください。シートにだけ記録されない場合は、
サーバーのエラーログに `contact.php: sheet forward failed` が出力されています。

## 注意

- `SECRET` は `contact.php` の `SHEET_SECRET` と同じ値である必要があります。
  変更する場合は必ず**両方**を同時に書き換えてください。
- **Apps Script のコードを修正したら、毎回デプロイし直す必要があります。**
  「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」で再デプロイしてください。
  保存しただけでは公開中の URL に反映されません。
- この `tools/` ディレクトリは合言葉を含むため、同梱の `.htaccess` で
  Web からのアクセスを禁止しています。削除しないでください。
- `SHEET_ENDPOINT` を空文字に設定すると、シート記録処理は実行されません。
